1. PENGENALAN & CARA MEMULAI APLIKASI
================================================================================

1.1 Apa itu ProPresenter Lyric Animator?
ProPresenter Lyric Animator adalah aplikasi desktop pendamping resmi untuk
ProPresenter v7 / v20.x yang bertugas mengambil alih presentasi lirik menjadi
sangat dinamis dan modern menggunakan animasi kinetik ala Adobe After Effects,
namun tetap setia 1:1 mengikuti font, warna, koordinat kotak teks, bayangan,
serta video background langsung dari ProPresenter tanpa membutuhkan NDI.

Keunggulan Utama:
Tidak membebani kartu grafis PC untuk transmisi video jaringan NDI yang berat.
Semua aset video dan slide dirender secara lokal dengan latensi di bawah 10ms.

1.2 Persyaratan Sistem
- Komputer / Laptop dengan OS Windows 10 atau Windows 11 (64-bit).
- Aplikasi ProPresenter 7.x atau ProPresenter 20.x yang sudah terpasang.
- Kartu grafis (GPU) yang mendukung akselerasi hardware.
- Jaringan Wi-Fi / LAN yang sama (jika ingin mengontrol via smartphone).

1.3 Cara Menjalankan Aplikasi
Anda cukup membuka folder aplikasi, lalu:
1. Klik dua kali file shortcut: "Jalankan_Lyric_Animator.bat"
2. Aplikasi akan otomatis mengompilasi pembaruan kode dan membuka jendela utama.
3. Anda dapat menekan tombol F12 di keyboard kapan saja untuk membuka atau
   menutup konsol DevTools jika ingin memeriksa log sistem.


================================================================================
2. KONEKSI PROPRESENTER & AUTO-DISCOVERY
================================================================================

2.1 Deteksi Jaringan Otomatis (mDNS / Bonjour Bawaan)
Aplikasi dilengkapi pemindai mDNS/Bonjour bawaan serta subnet scanning pintar:
1. Buka menu Pengaturan (ikon gear) -> tab "Koneksi & Port".
2. Aplikasi otomatis memindai jaringan lokal dan menampilkan daftar komputer
   ProPresenter yang aktif beserta alamat IP dan versinya.
3. Cukup klik tombol "Gunakan" pada nama komputer yang terdeteksi.
* Anda TIDAK PERLU menginstal software Apple Bonjour terpisah di Windows.

2.2 Pengaturan di ProPresenter (Cukup Sekali Saja)
Lakukan pengaturan ini sekali saja di komputer ProPresenter:
1. Buka ProPresenter -> Preferences (atau Settings) -> tab "Network".
2. Centang kotak "Enable Network".
3. Pastikan kolom Port berisi angka standar: 50001 (atau 1025).
4. Kolom controller password dapat dikosongkan (tanpa password).

2.3 Status Indikator di Header
- Hijau (Terhubung - OpenAPI): Aplikasi siap menerima slide lirik.
- Merah (Terputus): Klik tombol "Reconnect" di header untuk menyambung ulang.

2.4 Opsi Input Manual & Cek Koneksi
Jika jaringan Wi-Fi/LAN memblokir paket broadcast, Anda dapat memasukkan Host IP
(misal: 192.168.1.15) dan Port secara manual, lalu klik tombol "Cek Koneksi".


================================================================================
3. SINKRONISASI THEME, SLIDE & MEDIA 1:1 (TANPA NDI)
================================================================================

3.1 Cara Kerja Pembacaan Theme & Layout Slide
Aplikasi membaca aset ProPresenter secara langsung tanpa delay dan tanpa NDI:
- Font, warna teks, perataan (align), koordinat kotak teks, bayangan (shadow),
  dan outline terbaca otomatis mengikuti Theme Look atau layout slide asli.

3.2 Penanganan Multi-Textbox (Kotak Teks Ganda)
Slide dengan dua atau lebih kotak teks (misal: baris pembicara di atas dan
respons jemaat di bawah) dirender secara independen sesuai posisi aslinya tanpa
tumpang tindih.

3.3 Pemutaran Background Media (Video Loop & Gambar)
Video loop (MP4, MOV, WebM) dan gambar dari Media Bin ProPresenter diputar
secara lokal dengan sistem warm-slot pool tanpa jeda hitam (no black frame).

3.4 Indikator Layer ProPresenter
Pill indikator di panel kiri menampilkan status layer aktif:
Live Input, Media, Slide, Props (lengkap dengan nama prop aktif),
Announcements, dan Messages.


================================================================================
4. MENGATUR OUTPUT KE PROYEKTOR / VIDEOTRON LED
================================================================================

4.1 Deteksi Monitor Fisik Windows (DPI-Aware)
Aplikasi mendeteksi hardware display monitor fisik Windows secara native.

4.2 Memilih Layar Tujuan Output
1. Hubungkan kabel HDMI / DisplayPort proyektor atau videotron ke laptop.
2. Di Windows, tekan tombol [Win] + [P] lalu pilih mode "Extend" (Perluas).
3. Pada header aplikasi, klik dropdown monitor (misal: Layar 2 1920x1080).
   Jika baru dicolokkan, klik tombol refresh (panah melingkar) di sampingnya.

4.3 Menyalakan & Mematikan Layar Output (Live)
Klik tombol bulat monitor di sebelah dropdown:
- Lingkaran Merah (Offline): Layar belum aktif. Klik untuk membuka jendela
  Fullscreen tanpa border di monitor/proyektor tujuan.
- Lingkaran Hijau (Live): Layar sedang AKTIF. Klik untuk mematikan/menutup output.

4.4 Jendela Preview Pop-Out untuk Operator
Operator dapat mengklik tombol ikon pop-out di pojok kanan atas preview monitor
jika ingin memisahkan tampilan live ke jendela kontrol tersendiri.

5. ANIMASI LIRIK AFTER EFFECTS (IN & OUT)
================================================================================

5.1 Menyalakan / Mematikan Animasi (F2)
- Tombol Animasi ON (Hijau): Lirik masuk dan keluar menggunakan animasi kinetik.
- Tombol Animasi OFF (Abu-abu): Animasi dinonaktifkan, teks langsung mengikuti
  pergantian slide ProPresenter.

5.2 Pilihan 28+ Preset Animasi Teks
- Worship: Cinematic Blur & Rise (teduh syahdu), Smooth Slide Up, Elegant Fade.
- Per-Huruf: Typewriter (mesin ketik), Spring Pop Letter, 3D Flip X Reveal.
- Per-Kata: Kinetic Pop Words, Word Stagger Drop.
- Per-Baris: Line Mask Slide Up.
- Satu Slide: Zoom Blur Impact.

5.3 Mengatur Durasi Animasi
Gunakan slider durasi (0.3s - 3.0s) di panel kiri untuk mengatur tempo animasi.

5.4 Mode Transisi Saat Animasi Off: Fade vs Cut
Saat tombol Animasi dimatikan, Anda dapat memilih gaya transisi slide:
- Fade : Transisi crossfade simultan yang halus tanpa jeda kosong.
- Cut  : Pindah slide seketika tanpa transisi.


================================================================================
6. EFEK TEKS BERGOYANG KONTINU (WIGGLE & DISTORSI)
================================================================================

6.1 Pengenalan Efek Teks Kontinu
Berbeda dari animasi In/Out yang hanya berjalan di awal pergantian slide,
Efek Teks adalah gerakan mengalun kontinu yang terus hidup selama lirik tampil.

6.2 Menyalakan / Mematikan Efek Teks
Klik tombol "Efek Teks" di toolbar untuk mengaktifkan/menonaktifkan.

6.3 Pilihan Preset Efek Teks
- AE Wiggle Posisi  : Goyangan acak halus posisi teks.
- AE Wiggle Kata    : Goyangan dinamis tiap kata secara independen.
- AE Wiggle Handheld: Simulasi gerakan kamera panggung sinematik.
- Wave Swing        : Gerakan mengayun lembut seperti ombak.
- Glitch Displace   : Efek distorsi digital modern.
- Glow Pulse        : Efek pendaran cahaya berdenyut ritmis.

6.4 Mengatur Slider Intensitas & Kecepatan
- Slider Intensitas (0.2x - 2.5x): Mengatur jauhnya jarak goyangan teks.
- Slider Kecepatan  (0.2x - 3.0x): Mengatur tempo cepat/lambatnya goyangan.
* Catatan: Preset dan slider efek tetap dapat diatur bebas saat efek sedang OFF.

7. HITUNG MUNDUR (COUNTDOWN) & TEKS BERJALAN (RUNNING TEXT)
================================================================================

Kedua fitur ini dirancang untuk kebutuhan pra-ibadah, warta jemaat, maupun
pengumuman darurat. Keduanya dapat diaktifkan secara mandiri atau berbarengan
langsung dari tombol header (Countdown & Ticker) maupun menu Pengaturan.

7.1 Fitur Hitung Mundur (Countdown Overlay)
- Tampilan Angka Murni (No Background):
  Tampil murni sebagai angka modern tanpa kotak penutup latar belakang.
  Dilengkapi bayangan tebal (drop shadow) sehingga kontras dan terbaca jelas
  di atas video background terang maupun gelap.
- Mode Durasi Manual (Jam, Menit, Detik):
  Input waktu lengkap terdiri dari:
  * Jam   (j) : 0 - 99 jam
  * Menit (m) : 0 - 59 menit
  * Detik (s) : 0 - 59 detik
  Format teks otomatis menampilkan HH:MM:SS jika ada jam, atau MM:SS jika
  hanya menit dan detik.
- Mode Target Jam (HH:mm:ss format 24 jam):
  Cukup tentukan target jam ibadah dimulai (misal 09:00:00), sistem otomatis
  menghitung mundur sisa waktu secara presisi.
- Tombol Jeda (Pause) Aman:
  Saat countdown dijeda lalu ditekan Mulai lagi, hitungan waktu akan melanjutkan
  dari detik terakhir yang tersisa, bukan mengulang dari awal.
- Aksi Saat Waktu Habis (00:00):
  Pilihan "Sembunyikan Otomatis (Fade Out)", "Tetap Tampil (Hold 00:00)", atau
  "Tampilkan Pesan Selesai" (misal: "Selamat Beribadah!" tampil selama 3 detik
  kemudian otomatis memudar halus/fade out).
- Atur Ukuran Langsung di Layar (On-Screen Resize):
  Ukuran angka dapat diubah langsung di layar Live maupun Preview dengan:
  * Scroll Wheel Mouse di atas angka countdown.
  * Klik tombol floating mini [-] atau [+] saat kursor didekatkan ke angka.
  * Tarik handle sudut kanan bawah [⌟] untuk memperbesar/memperkecil.
- Batas Ukuran Otomatis & Anti-Overflow:
  Sistem membatasi ukuran maksimal font secara cerdas:
  * Maksimal 260px untuk mode jam (HH:MM:SS)
  * Maksimal 380px untuk mode menit (MM:SS)
  Serta mengunci batas koordinat geser (boundary clamping) agar teks countdown
  TIDAK PERNAH keluar atau terpotong dari batas layar monitor (1920x1080).
- Posisi Bebas (Drag & Drop):
  Angka countdown dapat digeser bebas ke posisi mana saja di layar.
- Animasi Smooth Fade:
  Angka countdown muncul dan menghilang dengan efek fade yang sangat halus.

7.2 Fitur Teks Berjalan Penuh (Full-Width Running Text / Ticker)
- Tampilan Penuh Selebar Layar (Full-Width):
  Teks pengumuman membentang penuh 100% selebar layar monitor (bisa diatur
  di posisi Bawah Layar atau Atas Layar).
- Perputaran Kontinu Tanpa Jeda (Seamless Infinite Loop):
  Teks berjalan berputar tanpa jeda kosong yang panjang dan tanpa jeda patah.
- Jalan Terus Tanpa Mengulang:
  Saat operator membuka menu Pengaturan lalu kembali ke layar Live, running text
  tetap berjalan terus secara mulus tanpa mengulang dari awal kalimat.
- Kotak Input Teks Luas:
  Kotak isian teks dibuat lebar dan leluasa untuk mengetik pengumuman panjang.
- Kustomisasi Tampilan:
  * Kecepatan berjalan (detik per putaran penuh)
  * Warna teks & Warna latar kotak
  * Transparansi latar kotak (0% transparan penuh s/d 100% solid)
  * Pilihan jenis font device Windows (Segoe UI, Arial, Montserrat, Poppins, dll)
- Animasi Smooth Fade:
  Teks pengumuman muncul dan menghilang dengan efek fade yang halus.

7.3 Layar Preview 16:9 di Menu Pengaturan
- Di tab "Hitung Mundur & Teks", terdapat layar preview interaktif rasio 16:9.
- Langsung Menampilkan Countdown & Running Text:
  Preview langsung menampilkan simulasi angka hitung mundur dan running text
  secara otomatis tanpa perlu mengaktifkannya ke status Live terlebih dahulu.
- Ukuran Layar Preview Terkunci Stabil:
  Ukuran monitor preview diatur permanen (480x270px) dan TIDAK AKAN MENGEČIL
  atau berubah bentuk saat ukuran font countdown atau running text diubah-ubah.

10. WEB REMOTE CONTROL DARI SMARTPHONE (VIA QR CODE)
================================================================================

10.1 Cara Kerja & Keunggulan Latensi Rendah (<10ms)
Operator atau Worship Leader (WL) dapat mengontrol animasi langsung dari
browser HP tanpa perlu menginstal aplikasi apapun. Komunikasi menggunakan
protokol WebSocket lokal berlatensi sangat rendah (<10ms).

10.2 Langkah Menghubungkan HP (Scan QR Code)
1. Pastikan smartphone dan laptop terhubung ke jaringan Wi-Fi yang sama.
2. Klik tombol "Kontrol HP" di pojok kanan atas header aplikasi laptop.
3. Pindai QR Code yang muncul menggunakan kamera smartphone atau Google Lens.
4. Buka tautan web yang tampil (misal: http://192.168.1.15:4989/#/remote).
5. Tombol di laptop otomatis berubah menjadi hijau: "Terhubung HP".

10.3 Fitur Kontrol Lengkap di Halaman Web HP
- Tab Navigasi HP: Berpindah mudah antara tab "⏱ Hitung Mundur & Teks" dan
  "🎨 Animasi & Lirik" dengan indikator lampu status Live.
- Layar Preview 16:9 di HP: Menampilkan simulasi tampilan layar proyektor
  secara live (angka countdown dan running text bergerak realtime) lengkap
  dengan badge status Live dan status timer.
- Tombol Sakelar Besar ON/OFF:
  * Tombol ON/OFF Countdown (Hijau = Live Aktif, Abu-abu = Off)
  * Tombol ON/OFF Running Text (Biru/Hijau = Live Aktif, Abu-abu = Off)
- Edit Countdown Lengkap di HP:
  * Pilihan mode Durasi Manual vs Target Jam (HH:MM:SS)
  * Kontrol Timer: Tombol Play (Mulai), Pause (Jeda), Reset, & status sisa waktu
  * Stepper 3 kolom sentuh nyaman: Jam (j), Menit (m), Detik (s)
  * Pengaturan ukuran font angka (px) dengan proteksi batas layar otomatis
  * Pilihan warna angka cepat (Emas, Putih, Cyan, Hijau, Merah) & custom picker
  * Pilihan cepat posisi di layar: Bawah Layar, Tengah Layar, Atas Layar
  * Pilihan aksi waktu habis: Sembunyikan Otomatis, Tetap Tampil, Pesan Selesai
- Edit Running Text Lengkap di HP:
  * Kotak teks pengumuman yang leluasa diketik di HP + tombol "Terapkan Teks"
  * Posisi di layar: Bawah Layar (Bottom) vs Atas Layar (Top)
  * Stepper kecepatan berjalan (detik per putaran penuh)
  * Pengaturan warna kotak latar & transparansi latar (0% - 100%)
  * Ukuran font teks (px) & pilihan jenis font device Windows
- Kontrol Animasi & Efek Teks:
  * Menyalakan / mematikan Animasi After Effects secara instan
  * Memilih transisi Fade atau Cut saat Animasi Off
  * Memilih preset animasi favorit dan mengatur durasi
  * Menyalakan / mematikan Efek Teks Wiggle, memilih preset, intensitas & kecepatan
- Tombol merah darurat F1 (Clear Layar Lirik) untuk situasi tak terduga.

10.4 Fitur Sambung Ulang Otomatis (Auto-Reconnect)
Jika layar smartphone sempat mati (sleep), koneksi otomatis tersambung kembali
saat layar HP dibuka tanpa perlu memindai ulang QR Code.


================================================================================
11. PANDUAN PEMECAHAN MASALAH (TROUBLESHOOTING)
================================================================================

11.1 Status Aplikasi "Terputus" dari ProPresenter
- Pastikan ProPresenter sudah dibuka di laptop.
- Buka Preferences -> Network di ProPresenter, pastikan "Enable Network"
  sudah dicentang dan port 50001.
- Klik tombol "Reconnect" di pojok kiri atas aplikasi Lyric Animator.

11.2 HP Tidak Bisa Membuka Halaman Remote
- Pastikan HP dan laptop tersambung ke Wi-Fi yang sama.
- Periksa Windows Firewall laptop (izinkan Private Networks).
- Pada modal QR Code di laptop, gunakan dropdown pilihan IP untuk memilih
  alamat IP Wi-Fi laptop Anda.

11.3 Output Layar Blank / Hitam di Proyektor
- Pastikan kabel HDMI/DisplayPort proyektor sudah terpasang kencang.
- Tekan tombol [Win] + [P] di Windows, pilih mode "Extend".
- Di aplikasi Animator, klik tombol refresh monitor, pilih layar proyektor,
  lalu klik tombol bulat merah agar berubah hijau (Live).

11.4 Mengakses Panel DevTools (F12)
Jika ingin melihat pesan log atau diagnosa sistem, tekan tombol [F12] pada
keyboard untuk membuka konsol pengembang Chromium.


================================================================================
12. TIPS PENGGUNAAN SAAT IBADAH / EVENT LIVE
================================================================================

1. Lagu Cepat / Praise:
   Gunakan preset "Typewriter" atau "Kinetic Pop Words" (durasi 0.6s - 0.8s)
   dengan efek "AE Wiggle Posisi" aktif untuk memberi energi visual pada lagu.

2. Lagu Lambat / Worship:
   Gunakan preset "Cinematic Blur & Rise" (durasi 1.5s - 2.2s) dengan efek
   "Wiggle Posisi" berintensitas rendah (0.6x) agar lirik mengalun syahdu.

3. Khotbah & Liturgi:
   Tekan shortcut [F5] (Liturgi) atau matikan Animasi dan pilih mode "Fade" agar
   pergantian ayat Alkitab dan respons liturgi tenang dan jernih dibaca jemaat.

4. Tombol F1 Darurat:
